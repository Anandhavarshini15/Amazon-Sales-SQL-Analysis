# Amazon-Sales-SQL-Analysis

##  Project Overview
Analyzed 50,000 Amazon Sales records using MySQL
to derive business insights on revenue, categories,
regions and customer behaviour.

##  Dataset Details
- Source: Kaggle
- Records: 50,000 rows
- Columns: 13
- Tool: MySQL Workbench

## Key Business Insights
1. Total Revenue = $65.7 Million
2. Beauty is top category — $11.1 Million
3. Middle East is strongest region — $16.6 Million
4. January is best month for sales
5. Wallet is most popular payment method
6. Higher discounts reduce revenue
7. Books has highest customer rating — 3.02
8. Average order value = $657
